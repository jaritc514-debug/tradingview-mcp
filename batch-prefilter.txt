BATCH PREFILTER — HTF Supply & Demand
=====================================
Scan your entire TradingView watchlist for fresh HTF Supply & Demand zones.
Do NOT run full analysis. Do NOT calculate entry levels. See rules.json for the full rulebook.

---

STEP 0 — PULL THE WATCHLIST
- Before running: make sure the "SCAN" watchlist tab is the active one in TradingView's right-hand panel.
  watchlist_get reads whichever watchlist tab is currently visible — it does not know about or combine
  other watchlists. If a different tab is active, this will silently scan the wrong (or empty) list.
- watchlist_get → the actual live symbol list. Scan every symbol returned, in the order given.
- Do not assume or hardcode a symbol list — always use what watchlist_get actually returns.

FOR EACH SYMBOL — run silently, no mid-scan output:

1. chart_set_symbol → switch to symbol

2. WEEKLY PASS
   - chart_set_timeframe → Weekly
   - data_get_pine_boxes(study_filter="Supply & Demand Pro", verbose=true) → record active Weekly zones
   - Read tags directly: formation (RBD/RBR/DBR/DBD), F, O, LoL
   - Freshness from bgColor: Fresh / 1st Touch (ignore inactive zones entirely)
   - If unreadable: flag pair as UNREADABLE, skip to next symbol

3. DAILY PASS
   - chart_set_timeframe → Daily
   - data_get_pine_boxes(study_filter="Supply & Demand Pro", verbose=true) → record active Daily zones
   - Same tag/freshness reading as Weekly

4. HTF COVERAGE
   For each Daily zone, check if it sits inside or overlaps a Weekly zone of the same type.
   HTF Coverage = Yes / No. Report both either way — not a filter.

5. LEG-OUT QUALITY
   Base length already filtered by the indicator (max 6 candles) — do not re-validate.
   For each zone, pull candles via data_get_ohlcv around its formation and classify the breaking candle:
     ≤49% body = indecisive | 50-75% = decisive | >75% (abnormally large) = explosive
   Leg-out quality = Explosive / Decisive.

6. TREND CONFLUENCE (tag only)
   - data_get_pine_tables(study_filter="Trend Direction Pro") → Daily and Weekly rows
   - Tag each zone trend-aligned or trend-conflicting. Never excludes a zone.

7. VALUATION CONFLUENCE (tag only, unverified)
   - data_get_pine_tables(study_filter="Campus Valuation Tool") or data_get_study_values as fallback
   - Report raw read or "unverified" if it fails. Never excludes a zone.

8. PROFIT CHECK
   Nearest opposing zone (Fresh or 1st Touch) in the direction out of this zone.
   Path = Clear / Boxed in.

9. RISK TIER
   Apply the mapping from rules.json based on timeframe, freshness, leg-out quality, HTF Coverage.

---

OUTPUT — print after every symbol on the watchlist has been scanned:

SORT ORDER:
1. HTF Coverage: Yes, tier 1.5% — highest conviction first
2. HTF Coverage: Yes, tier 1% or 0.5%
3. HTF Coverage: No, any tier — still real zones, just no Weekly confluence
4. UNREADABLE — always last, separated by divider

TABLE FORMAT (one line per zone — a pair may appear more than once if it has both a Weekly and Daily zone):
[PAIR] | [Weekly/Daily] | [Supply/Demand — formation] | [Fresh/1st Touch] | [Leg-Out] | [HTF Coverage] | [Trend tag] | [Path] | [Risk Tier]

─────────────────────────────────────────────────────────────────────
⚠ UNREADABLE — verify manually before relying on this pair
[PAIR] | Supply & Demand Pro or Trend Direction Pro unreadable
─────────────────────────────────────────────────────────────────────
